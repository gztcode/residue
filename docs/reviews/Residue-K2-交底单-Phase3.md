## 四、已知的口径风险（**不隐瞒，供你判断是否影响你的工时**）

1. **A-9 的七页 UI 是本阶段最大不确定项**：R2 只定了「界面不自己算数」，没定视觉。视觉基线属 R1.5（设计评审）——**本产品此前从未走过 R1.5**。**要么现在补 R1.5，要么 A-9 降级为「七页骨架 + 语义位占位」，把视觉推到 R3.8 走查前**。这是范围问题，需要你拍板。
2. **A-7 迁移与断电路径**是本阶段最难自测的部分——单测能覆盖状态机，但「断电落在哪一步」只能靠真机演练。
3. **`a` 在目标机器上可能 ≥ 1**（C2 计数制裁决的直后果）→ 门槛可能长期不可满足。**这不影响实现，但会影响 B-1 里 AC-08 相关用例的构造**（用例要能在 `a = 0` 与 `a ≠ 0` 两种态下都构造出来）。

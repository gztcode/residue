## 5. 复核与冻结

**复核性质**：CR-004 应用后的**三方轻量影响面复核**（非 R1 整轮重开），依据 CR-003 §5「CR 路径不占单轮闸」先例。提案人回避。

**复核范围**：仅第 2 节 12 条 + H1–H7 + 三条建议项落实 + B-CR003-1 是否真正关闭。三方各判五项：

1. **B-CR003-1 是否消解**：产品内是否还存在任何外部入口、可点击控件、静态文本位、或需要承载页的界面落点；434 行关闭登记是否足以让设计侧判定「无落点问题」。
2. 12 条改动有无新增不可判定条款；P1 第三类删改后，「零外发」字面承诺与 P1 / AC-01 / AC-12 判定是否仍一致、有无新盲区。
3. H1–H7 逐条：尤其 D1 / D3 / D4 有无被连带改动、零外发有无被「回退」误读为放宽、交付物有无被写成新功能、R2 项有无混进契约。
4. 三条建议项（S-Q1 / S-Q2 / S-D2）是否落实到位；S-D1 是否如实作废、有无残留。
5. 有无新增 AC 编号 / 页面 / 状态类 / 状态词 / 机制 / 能力 / 交付物类别；20 条 AC 主体、§8 七类状态、7 页 × 1 形态是否仍成立。

**判定规则**：沿用「三方并列必要视角」——架构判可实现性、质量判可判定性、设计判能否被界面与状态表达；**任一视角判未关闭即不冻结，不得两票覆盖一票**。三方各给「通过 / 不通过」+ 两个数字（未关闭阻塞项数 / 未处置建议项数），不使用「有条件通过」。

**冻结状态**：**三方全通过且两个数字均为 0** → 冻结 `Residue-PRD-v3.2.md`。冻结的仍只是**契约条文**，不含 V1–V8 取值与 C2 / C3 取值（冻结契约 ≠ 参数已定）。复核不通过则不冻结，按阻塞项另开处置路径。C2 / C3 仍为 R2 / Phase 2 开工前置，本单不解除。

## 本轮六个追问的回应

**追问 1 · 重做落点核对表，确认没有任何一行再是「无落点」**

**追问 2 · B17 的「本轮未结算」——现在第 ⑤ 页在报告产出前是：①「参与/仅报告」+ ②来源名 + ③「本轮未结算」+ ④「本轮未结算」+ ⑤「该来源不适用（无观测通道）」+ ⑥「本轮未结算 · 检查 128」+ ⑦「本轮未结算」。请直接判断用户会怎么读，特别是 ⑥ 复合列「一半占位一半真实」是否仍困惑。**
**按 AC-09 第 861 行逐列读得通**：用户能读出「**这一轮还没出结果，但已经在检查了**」——**⑥ 的半占位半真实本身不困惑**（两个槽位分工明确：误判待算、检查实测），**前提是槽位标签「误判 / 检查」不被占位串顶掉**（S5 建议明确这一句）。
**但这个组合只在 AC-09 里成立**：§6 只补了 ⑥ ⑦，③ 仍写「样本 `<K>` / 总量 `<T>`（其中失联 `<J>`）」且 `K + J = T` 是硬断言 → 产出前只能填「样本 0 / 总量 30（其中失联 30）」→ **用户读到的是假值**（B19）。**④ 也缺**（AC-09 说填「本轮未结算」，§6 仍写只填 `H`）。
**结论：⑥ 的半占位半真实不用改；要改的是 §6 的 ③④ 两列 + ③ 列头时点**——「④ 显示门槛 30 + ③ 显示样本 0」这一组合比「⑥ 一半占位」更容易被误读成「差一点就够」。

**追问 3 · B18 的五级优先级——现在穷尽了吗？还有第 6 种可能吗？用户会不会觉得「否（因 X 未判定）」和「否（因 X 未达标）」本质一样、只是措辞不同？**
**「否」的成因已穷尽，无第 6 种**：页级取「否」的成因只可能是 ① 报告产出前 ② 空判定域 ③ 全部来源未取得 FDA ④ 某来源未取得 FDA ⑤ 存在未达标来源——五类，与 M4 两式 + AC-09 两条例外一一对应。
**「未判定」vs「未达标」不是措辞差别，是两类事实**：「未判定」= **没资格判**（没有 Full Disk Access，连 `a` / `b` 都不判，是 §8「无权限」类、用户有动作可做——去授权）；「未达标」= **判了、且没过**（`K < H` 或 `a ≠ 0`，用户要等样本或改不掉误判）。用户从括注里能分辨出「**要不要我动手**」——这是本设计最有价值的一条可区分性，**建议不要再往括号里加词**（S10 只补「是」这一级即可）。
**残留**：⑤「其余」按字面会把「全部达标」也读成「否（因 X 未达标）」，但同句已写「取「否」时须带至少一个未达标来源名」+ 与开关状态一致（是 ⟺ enabled），可解 → 降为建议项 S10。

**追问 4 · 轮次表述三处形式（第 ③ 页「第 N 轮 · …」、第 ⑤ 页页级「本轮（第 N 轮）可点亮：否」、第 ⑤ 页上一轮行「上一轮：…」）——v4.5 未改，请给一个统一形式，或明确说这样就够了。**
**不够，仍需统一，保持建议项、不阻塞**（理由：三处指向三件不同的事——③ 页进度、⑤ 页页级开关、⑤ 页上一轮结算值——用户不会因形式不同而误判内容；真正会造成误读的是括号形式「本轮（第 2 轮）」，它像另一个编号）。
**统一形式（前置数字式，三处同构）**：
- 第 ③ 页全局项：「**第 `<N>` 轮 · 观察期 `<已观察>/14` 天**」（已有，不动）
- 第 ⑤ 页页级：「**第 `<N>` 轮 · 本轮可点亮：否（因 `<来源>` 未达标）**」
- 第 ⑤ 页上一轮行：「**第 `<N−1>` 轮 · 样本 `<K>` / 总量 `<T>` · 未达标 · 冻结于 `<YYYY-MM-DD>`**」
另：**§6 全文 0 处「轮次」、0 处「上一轮」**（S2）——这是设计直接依据侧的缺口，须一并补；**M1「全文只此两串」与文件头②括注的冲突**（S3）也要一并处置，否则「唯一样式串」不可校验。

**追问 5 · 第 ③ 页与第 ⑤ 页的口径对照——用户能否在两页间建立一致的心智模型？**
**能，且不构成口径冲突**：③ 页说**进度**（这轮走到第几天，「第 2 轮 · 观察期 3/14 天」），⑤ 页说**结算状态**（这轮的结果还没出，矩阵各列占位，页级「否（观察期未满）」）。两页互补、不重复、无矛盾措辞。
**两个残留可读性缺口（均不阻塞）**：① ⑤ 页页级不带进度 → 用户想知道「还差几天」必须跳回 ③ 页（S11，同一行多一个值即可）；② ⑤ 页 ③④ 若按 §6 填「样本 0 / 门槛 30」→ 与 ③ 页的「3/14 天」并列时，用户会拼出「**样本不够、门槛 30、还差 11 天**」的错误因果（真实是「**还没开始算样本**」）→ 这正是 B19 的假值在两页之间的放大。

**追问 6 · §8 七类是否仍自洽？**
**类数与实例仍自洽（7 类全部有本期实例，「观察期尚无数据」是唯一明确标本期无实例的义项）**，B11 的实删没被顶回。
**两处措辞不自洽（均非阻塞，进建议项）**：① §8 开篇「当前**唯一一处**」与「超限」行现存的无触发物义项「规则更新后观察期归零」冲突 → **S7**；② §8「空」类行「无可扫描来源 / 无清理候选 / 无执行日志 / 观察期尚无数据（本期无实例——…）」的括注位置可被读成「四项全是本期无实例」→ 会丢掉两个有实例的空态（AC-08 组 A 用例③要求呈现）→ **S8**。

## 结论说明（给下游的一句话）

v4.5 把上轮 2 条里的 **B18 彻底关掉**（M4 的 FDA 行加了时间限定 → 同格两式撞车消解；AC-09 与 §6 同源同序写死五级「否」优先级 → 组合态取值唯一、无第 6 种）；**B18 的修法完全成立**。**B17 的修法只成立一半**：§6 第 ⑤ 页承载页指定已补 ⑥ 左值占位 / ⑥ 右值 `b` 照常 / ⑦ 结论封闭值域仅适用于产出后（产出前的「误判 0」+「结论：未达标」两类假值已消解），**但同一段的 ③ 样本数列、④ 门槛列、③ 列头「冻结于」时点三处仍停在「产出后」形态**——实施方照 §6 画表，产出前 ③ 只能填「样本 0 / 总量 30（其中失联 30）」，用户读成「**我的缓存一个都没归因出来、样本为零**」，与同排「结论：本轮未结算」自相矛盾（B19）；且产出前 + 未取得 FDA 的来源，⑥ 右值 `b` 无任何取值规定，实施方填 `0` 会被读成「**从未被扫描过**」（与 M5 唯一解释冲突）、留空则违反「每项均须非空」（B20）。两条合计**不新增页面、不新增状态类、不新增未达项类、不新增用户动作、不新增 AC 编号**，全部在既有 7 页的既有语义位上以 **3 句话**改完；改完后四维度 29 行可见结果全部有落点、产出前无任何假值可能，**下一轮即可通过**。

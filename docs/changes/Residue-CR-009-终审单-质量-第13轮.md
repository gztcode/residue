## `a` 判据专项审查（阳性差集 `a` += \|`P_now` − `P_prev`\|）

| 检查项 | 判定 | 依据 |
|---|---|---|
| **必查 1-1：阳性差集是否恰好等于 L0 误判？** | **否** | 差集判据的语义是「**本轮新变成被持有**」，而 M4 行 134 的「唯一判据」语义是「**首检无引用 → 复检有引用**」。二者在**两个边界上不等价**：① **首轮**（`P_prev` 无上一轮 → 初值 ∅）：差集把「首检即有活引用」的候选**计为误判**，而行 134 明确要求「首检无引用」这一前置状态 → 真实机器上 `npm`/`uv` 常驻持有者会让 `a` ≥ 1 **恒成立** → 组 B 的「`a` = 0」门槛**恒不可满足**（恒真的反向形态）；② **间歇持有**：差集只与**紧邻上一轮**比较、不查历史 → 同一候选反复被持有会**重复计数**，而行 134 明写「同一条候选只计一次」。→ **同一台机器、同一操作序列，两个 `a` 读数** → 见 **Q23** |
| **必查 1-2：间歇性持有会不会重复计数？** | **会（且与「只计一次」矛盾）** | `P_prev` 每轮被替换为 `P_now`（137 行「随每轮判定滚动替换」）→ 候选 X 在轮 2 被持有（`a` += 1）→ 轮 3 释放（差集 ∅，`P_prev` 清空 X）→ 轮 4 再被持有（差集命中 X）→ **再次 `a` += 1**。而行 134 声称「同一条候选只计一次（由『该候选已在上一轮阳性集合 `P_prev` 中 → 本轮差集不再命中』**自然实现**）」——该声称**只在连续持有时成立**，间歇持有下**不成立** → 见 **Q23** |
| **必查 1-3：`a` = 2 现在可构造吗？** | **可构造，但读数不唯一** | 路径甲（两个候选各连续持有一轮）：X 在轮 1→2 被持有、Y 在轮 2→3 被持有 → 差集得 `a` = 2；路径乙（同一候选间歇）：X 在轮 2 被持有、轮 3 释放、轮 4 再持有 → 差集得 `a` = 2。按行 134「同一条候选只计一次」读法，路径甲 = 2、路径乙 = **1** → 两个读数。**结论：`a` = 2 物理可构造 ✓，但「构造方式 ↔ 读数」的映射不唯一 ✗** |

### 团队点名的三处推演（逐条亲手推）

**① `K` / `J` 是否仍循环、是否存在第二条路径算出不同的 `J`**

- 按 M3（唯一式）：`T = 30`，快照逐条归因得 `K = 28` → `J = T − K = 2`，`K + J = 30` ✔ **成立**。
- 按 AC-08 组 B 判定的字面（`K = T − J`，`J` 为派生量）：若 `J` 由实现侧独立给出（归因直接得 2），则 `K = 30 − 2 = 28` —— 此路径下 `K` 是由 `J` 推出的，**`K + J = T` 成为构造上恒真的断言**（先定 `J` 再定 `K`，恒等式不可能不成立），AC-09 ③ 因此**不可证伪**；而 M3 路径下 `J = T − K` 会吸收 `K` 的归因误差，③ 同样恒成立。
- **两条路径给出的是不同的事实**：M3 路径下 ③ 通过只证明「`K` 归因正确」；组 B 路径下 ③ 通过只证明「`J` 归因正确」。二者同时被写进契约，验收人无法判定 ③ 通过究竟证明了什么。
- **结论**：`J` 自身在 M3 口径下唯一（`J = T − K`），但全文仍存在第二条能给出不同 `J` 的路径（组 B 口径下 `J` 是独立量）。**非循环性只在 M3 单条路径上成立，契约层未封住第二条路径。** → 阻塞 #5。

**② M4 的 `a` 判据在真机上是否可执行**

不可执行，且 `a = 0` 仍可恒真，**R2 未被修掉**：

- **「复检」在全文无定义。** P-L0 只定义「L0 检查窗口 = 首次检查时刻 → 删除动作前二次检查时刻」，两次检查**均由删除动作驱动**；影子期不删条目（AC-09 Then）→ 影子期不存在该窗口。
- **「复检怎么触发」无答案。** 全文**没有任何 AC 要求产品在观察期内执行 L0 判定**（AC-05 / AC-17 的 L0 都在删除链路上）。M5 只在计数口径里「假定」影子期有 L0 首检（「影子期内的 L0 首检同样计数」），AC-08 组 A 反而承认 `b = 0`（`L0 未检查（检查 0 次）`）为合法展示态。
- **「产品怎么知道首检发生在哪一刻」无落点。** V4「L0 检查时刻」是含两个子值的复合字段（首次 / 二次，语义为删除窗口）；M6 又规定举证链行的记录时刻取「首次检查时刻」。**「复检时刻」在 V4 八字段里无处可存**，而 M4 的写入时刻恰恰是「复检时刻」。
- **推论**：实现方按「不执行」→ 首检不存在 → M4 判据永不命中 → `a ≡ 0` 恒真（无论真实误判率多少），组 B 的「`a = 0`」不可失败；实现方按「执行」→ 需要一条文档未给出的执行与记录机制。两条路都通不过「可执行」这一关。→ 阻塞 #2。

**③ M5 的 `b` 计数对象、重复计数、`b ≥ 1` 是否名副其实**

- **重复计数**：M5 已明写「同一条候选被重复检查则重复计数（每日重扫同一候选 → 每日各计 1）」→ `b` 随天数线性膨胀，量纲是「检查次数」而非「检查强度」。
- **膨胀是否有害**：无害于判定，但**使 `b ≥ 1` 的门槛语义极弱**——它只保证「至少检查过一次」，不构成任何充分性证据。作为「防止 `a ≡ 0` 恒真」的下限护栏是可接受的（本身不必作为阻塞）；**真正的问题是这个下限的可达性从未被写死**（阻塞 #2）。
- **真正的阻塞在 `b = 0` 分支**：AC-08 组 A Then 给了 `b = 0` 的独立文案「`uv cache · L0 未检查（检查 0 次）`，**仍属既有三类未达项之一，不新增未达项类**」，但组 A Given 的来源项只有 `{样本不足 (K<H), L0 误判 (a≠0)}` —— `b = 0` 时 `K ≥ H` 与 `a = 0` 同时成立，两类来源项都不成立，这条文案**不属于任何一类**。→ 阻塞 #3。

**④ M1「本轮计数日」失败日不计入 → 观察期是否会永远不满 / 是否死局**

- **扫描长期失败（用户不开机 / 磁盘满 / CLI 失效）→ 观察期永不结束、永不点亮**：这是**已如实登记的已知边界**（文件头 ①「不设超时上限……扫描一直失败则永远不点亮，因为无法完成结算」，并给唯一文案「观察期未满 · 待结算扫描（无需操作）」）。作为如实登记，我**不判为阻塞**。
- **但另一条死局没有被登记，且是 v4.2 的新写法带来的**：M1 算法把计数日定义为「成功扫描的**累计次数**」，而文件头定义为「成功扫描**日数**」。用户一天手动触发 14 次扫描即可在同一天把 14 个计数日走完 → 观察期实际不足 1 天，第 ③ 页却显示「观察期 14/14 天」，样本 `K` 只反映 1 天内的归因。**14 天观察期这一对外承诺与 S2「每轮观察期 14 天」的观测窗口同时失真。** → 阻塞 #6。

## 二、`a` 判据专项审查（`F` ∩ `P_now` − `C_done`）

### 2.1 判据方向是否成立

**判定：方向成立（阳性差集的四条病灶确实被消解），但判据尚不可执行、语义尚不唯一 → 判据「有条件成立」，未完全成立。**

`F` 位图是本轮的关键改进：`F` 承载「**曾判阴性**」这一历史 → ① 「自始被持有者」永不进 `F` → 永不计误判 ✓（消解 13-A1 的首轮全量误计）；② `F` 一经置位不再清除 → 「曾判干净、后被持有」必被捕获 ✓；③ `− C_done` 单调 → 持续持有、间歇持有均不重复计 ✓（消解 13-A2）。**这三条是本轮真正的修复，且方向正确。**

**但判据仍有两处硬伤**：
- **判据语义在 M4 判据行内自相矛盾**（14-A1）——新公式与旧语义句并存且不等价；
- **载体缺一项使其不可执行**（14-A2）——`F` 是位图，但**位槽如何分配、候选身份键是什么，载体三项里没有**；而候选集合逐日churn（uv/npm 缓存新增、剪枝、重建），位槽若随名次漂移，读到的位就属于**别的候选**。

### 2.2 逐项检查

| 检查项 | 判定 | 依据 |
|---|---|---|
| **判据语义是否 = L0 误判** | **不成立（两读）** | L134 新公式 = 「**曾**判阴性 → 其后**某次**扫描阳性，且只计一次」；L134 同句后半「判据语义 = 「本轮新变成被持有的候选」——即「上一轮还干净、这一轮被持有了」」= **相邻两次扫描的阴转阳**（= 已实删的 CR-015 语义）。二者在「间歇持有」上分岔（见 14-A1 反例：1 vs 2）。L135「唯一判据（与上行同一口径，不另立第二套）」与上行**不同一口径** → 该自称不成立。 |
| **`F` 的置位时点是否正确（首检阳性者永不计）** | **成立** | `F` 只在「候选**首次判定为阴性**时置位」；首检即阳性者 → 判为阳性 → 不置位 → 后续若持续被持有，`F` 始终不含它 → 永不计误判 ✓（这正是「自始持有者不是误判」）。但须注意其**代价**：判为阳性的那一瞬也是「未被判阴性」→ 若该候选**中间**转为阴性（无人持有）→ 置位 → 其后**再**被持有即计 1（**该计数对应的不是「首次判定错」而是「中途判错」**，语义仍在「曾判阴性」之内，可接受）。 |
| **`F` 的位在候选消失后是否清除** | **规定为「一经置位不再清除」——问题不在位本身，在位槽归属** | 位不清 → 同一候选被手删后又重建 → 若身份键含 birthtime → **新身份 = 新候选 = 新位槽** → 不会被重复计 ✓（问题稿的回答正确）；**但若位槽按名次/路径分配且位图不回收** → 新候选可能落进**旧候选遗留的已置位槽** → 被误计 → 见 **14-A2**。**位图空间只增不减 + 候选逐日churn = 位槽耗尽后无新槽可分**，载体未写位槽分配与回收规则。 |

| **`F` 与 `C_done` 的规模是否可接受** | **成立（量级）/ 表述不成立** | `F` = 300 万候选 ≈ 375 KB（每来源一份，判定域内来源当前仅 `uv` cache / `npm/_npx` 两类 → 全机 ≤ 约 1 MB）；`C_done` = 累计误判候选数（与真实误判次数同阶，远小于候选总数）→ **量级完全可接受**。但 L138 载体字段①写「**与候选数有关但与行数无关**」（对），同单元格末尾总结句写「**与候选数无关**（每来源 1 份，字节数可忽略）」（**错**），L134 残留句③写「**载体规模 = 被持中的候选数 ≪ 候选总数**」（**错**）→ 三处自述互斥 → 落建议 **14-S1**（上轮 13-S2 未对齐）。**注：载体规模不构成阻塞**（375 KB 无论何种口径都可接受）。 |

## 六、本轮结论

- **结论：不通过**（阻塞项 2 条 / 建议项 8 条）
- **上轮 7 条修法：成立 6 条（13-A2 / A3 / A4 / A5 / A6 / A7），不成立 1 条（13-A1）**
- **`a` 的判据（`F` ∩ `P_now` − `C_done`）：方向成立、可执行性未闭合。** 本轮是**第四次尝试里第一版在数学上真正能表达「首检」的方案**：`F` 位图承载「曾判阴性」这一必要历史 → 「自始被持有者」永不计误判 ✓；`C_done` 单调 → 「同一条候选只计一次」有载体、可执行 ✓；`F` / `C_done` / `a` 随应用版本一并清零 → 「换版即脏」消解 ✓。**但仍有两处硬伤**：
  1. **14-A1**：M4 判据行内**并存新旧两套判据语义**（新公式「曾判阴性→其后某次被持有、只计一次」 vs 残留句「本轮新变成被持有 / 上一轮还干净」）→ 间歇持有场景下同一台机器两个 `a`（1 vs 2）；且残留句引用的 `P_prev` 已不存在于载体 → L135「与上行同一口径」的自称落空。**这是定点措辞删改，不需要改机制。**
  2. **14-A2**：位图的**位槽归属规则与候选身份键缺失** → 候选逐日 churn 时读到的位可能属于**别的候选** → 或把从未判阴性者误计（误报恒真以更窄形式回归、该来源永不可点亮），或把真误判漏计（门槛被绕过）；「300 万 bit / 300 万候选」的字面实现（哈希）碰撞率极高 → 同一后果。**这是补一条定义（位槽分配 + 身份键 + `C_done` 同键），不涉及判据方向。**
- **除上述两条外，四个维度的其余机制面本轮全部闭合**：观察期（13-A4 三处同源成立 → 无两读）、样本（`K + J = T` 唯一式 + 冻结时点分列不变）、留存（举证链粒度收窄 + 「当前窗口」有定义 + 终止性不再断言「必然可达」+ 写入时序上保护条款不产生互斥）、AC-18 分母（字段级 + 测量时点两处同源）。
- **死局结论**：L0 的「误报恒真」**方向性病灶已消解**（首轮全量误计不再发生），但因 14-A1 / 14-A2，**不能宣布 L0 死局已消解**——`a` 目前仍不可判定（两读 / 不可执行）；一旦 14-A1 与 14-A2 落地，L0 维度的机制即闭合。
- **本轮不建议整体重做**：两条阻塞均为定点修（一条删三处残留句 + 一条补位槽分配定义），不动判据公式方向、不新增 AC 编号 / 页面 / 状态类 / 状态词 / 用户动作、不触碰已裁决项（四维度范围 / `H = min(30, T)` / 14–90 天 / 200 MB / 14 日豁免 / S4 / AC-16 / L2 门槛 / 期内样本进度 / C2 计数制）。

v4.1 把「期内只出天数」做干净了，观察期/样本/L0 三个维度的主体判定项在 7 页里都有可指认的落点，方向是对的、可闭合。**不通过只因两件事**：一是「自动开下一轮」这个新补的出口没有在界面上留下任何痕迹，反而让它以前的所有期外文案失效（B3，最重）；二是留存维度作为四个交付维度之一，**至今没有任何页面或状态承载它**（B1）。B2 / B4 / B5 / B6 是落点内部的自相矛盾，改文案与一格显示值即可，不需要动机制。
6 条修法合计**不新增页面、不新增状态类、不新增未达项类、不新增用户动作**，全部落在已有 7 页的既有语义位上。

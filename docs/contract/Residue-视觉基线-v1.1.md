## 二、语义色（**只有两档状态色，不新增第三档**）

| 角色 | 值 | 用途 |
|---|---|---|
| 背景 | `#0F1115` | 页面底 |
| 表面 | `#16191F` | 卡片 / 表格容器 |
| 主文字 | `#E6E8EC` | 正文 |
| 次文字 | `#8B9099` | 辅助 / 单位 / 说明 |
| **信号色（唯一强调）** | `#5E6AD2` | 主按钮、可点亮、焦点环、选中态 |
| **危险色** | `#D9534F` | 删除确认、错误态、不可逆提示 |
| 中性提示 | 次文字色 | 空态、加载文案（**不加第三种色**） |

**规则（v1.1 改写：从「数次数」改成「取优先级」）**

### 信号色：优先级规则

**唯一名额仍然只有一个**，但只回答「给谁」，不再需要「数几次」。每屏**只兑现优先级最高的一个**，其余全部退到中性表达：

| 优先级 | 承载物 | 条件 |
|---|---|---|
| **1** | **主行动按钮** | 每屏最多一个可执行主按钮（提交 / 确认 / 清除） |
| **2** | **焦点环** | 键盘焦点，且**仅当该屏无主行动时** |
| **3** | **选中态** | 侧栏 / 分段控件当前项，且**仅当该屏无主行动、无焦点环时** |

> **为什么改**：v1.0 把「选中态」列为合法用途，而本产品**每一页都有侧栏选中态** → 唯一名额在页面还没开始工作时就被导航吃掉了，**任何页面只要有主行动必然违规**。这是规则的结构性缺陷，不是实现乱用。

### 逐行属性标记：**永久不进入信号色**（不是例外，是不属于合法用途）

「可参与自动删除 / 仅报告 / 可恢复 / 已恢复 / 已阻断」这类**逐行属性**天然有 N 个，与「稀缺的一次」在语义上不相容。合法形态（三处一致）：

| 项 | 值 |
|---|---|
| 底色 | `textSecondary` @ **12%**（不得更低，否则对比度不达标） |
| 文字色 | `textSecondary`（`#8B9099`） |
| 圆角 | `radius.badge` = 4 pt |
| 文字 | 11 pt |
| 内边距 | 水平 8 / 垂直 **4**（4 栅格） |
| 图标 | **9 pt**，与文字间距 4 pt |
| 整体高度 | ≈ 22.5 pt，在 32 pt 行高内居中，不撑行 |

**图标位分配（五标签五图标，不得复用）**

| 标签 | 页 | SF Symbol |
|---|---|---|
| 可参与自动删除 | ② | `bolt.circle` |
| 仅报告 | ② | `doc.text` |
| 可恢复 | ⑦ | `arrow.uturn.backward` |
| 已恢复 | ⑦ | `checkmark.circle` |
| 已阻断 | ⑦ | `slash.circle` |

**可辨性兜底**：灰色徽标必须在 11 pt 下可读，文字与徽标底对比度 **≥ 4.5:1**。实测 `#8B9099` on `#8B9099`@12% over `#16191F` = **4.65:1**——**仅高于门槛 0.15，余量很薄，必须实测复验**。若实测不过，退回「配额制（全表最多 3 个）」而不是加底色百分比糊过去。

**危险色**：只用于「这一步不可逆」的提示。**不引入绿/黄/蓝等额外语义色**——七态靠图标与文案区分，不靠颜色堆叠。

## 三、八态视觉映射（每态 = 一行文案 + 一个图标位）

| 状态类 | 图标语义 | 文案位置 | 颜色 |
|---|---|---|---|
| **空** | 无图标 | 内容区居中，一句主文案 + 一句操作指引 | 中性 |
| **加载** | 环形进度 | 内容区顶部，进度文案 + 取消按钮 | 中性 + 信号色（进度环） |
| **错误** | 感叹号 | 内容区，**错误码 + 一句可执行动作**（不只报错） | 危险色 |
| **无权限** | 锁 | 内容区，「所缺权限」+ 授权指引条目 ID | 危险色 |
| **超限** | 上箭头横线 | 行内或表头旁，提示已触顶 | 危险色 |
| **并发冲突** | 两条交叉箭头 | 状态条 | 中性 |
| **超时** | 时钟 | 内容区，「已超时 + 可续扫」 | 中性 |
| **只读**（本产品特有） | 铅笔划线 | 页面顶部固定说明条 | 中性 |

**规则**：错误态必须给**可执行动作**（如 `E-303` → 「释放磁盘空间后重试」），不能只显示错误码。

## 四、语义位类型化（让「L4 禁止算术」靠类型而非纪律）

**动机**：R2 §3 定了「界面禁止任何算术」，但靠纪律迟早破。改成**类型约束**：界面只能从下列封闭枚举里取内容。

```swift
enum SemanticSlot {
    case text(String)              // 静态文案
    case metric(Int, unit: Unit)   // 数值 + 单位（值由 Metrics 算好，界面不换算）
    case ratio(Int, Int)           // 「27 / 30」两值（界面不自己算差）
    case duration(days: Int)       // 剩余天数（可为 nil → 显示「—」）
    case stateLabel(StateLabel)    // 七态之一
    case unavailable(reason: String) // 「—（由更高版本维护）」/「本轮未结算」
}
```

**硬约束**：
1. `SemanticSlot` **不接受闭包、不接受算术表达式**——数值必须在构造 `SemanticSlot` 之前由 `Metrics` / `GateEvaluator` 算好。
2. **「不可用」是一个正式的槽位值**（`.unavailable`），**不是空字符串、不是 0**。这直接落实了「`T` 待重取 → 显示 `—` 而非 0」这条契约要求。
3. **比例型槽位（`.ratio`）两个值分别来自 `K` 与 `T`**——界面不显示「差 3 条」这类自己算出来的结论。

## 五、七页骨架的布局约束（只定骨架，不定视觉细节）

| 页 | 骨架 | 必须有的语义位 |
|---|---|---|
| ① 只读存储总览 | 三区块 + 状态条 + 加载态 | 三区块各一个 `.metric`；状态条承载「并发冲突」 |
| ② 环境明细与候选清单 | 分页列表（≤ 200 行/页） | 每行一个标签（可参与自动删除 / 仅报告）+ `.metric(bytes)` |
| ③ 清理策略配置 | 表单 + **两个不重叠的语义位**（清理策略参数 / 规则版本） | 开关区未达项文案（带轮次）；剩余天数 `.duration` |
| ④ 授权与隐私 | 表单 + 一键清除按钮 | 采集范围说明 + 清除范围说明（含「不重置观察期与 L0 误判记录」一句） |
| ⑤ 影子观察期报告 | 矩阵 + 页级状态行 + 「上一轮」行 | 矩阵七项全部 `.metric` / `.ratio`；**③ 列的两个冻结时点标注在「该列表头内」分行**（列名 + 两行副标，表头块高 60 pt），**数据单元格只放 `.ratio` 一行**；只读态显示「只读，不结算」 |
| ⑥ 确认清理（抽屉态） | 抽屉 + 不可逆提示 | 本次将删除条目数与字节（`.metric`）+ 危险色确认按钮 |
| ⑦ 举证链 / 执行日志 | 列表 + 恢复入口 + 导出按钮 | 每条执行记录带「可恢复 / 已恢复 / 已阻断」标签；留存口径两行同址（14 日 + 90 天/200 MB） |

**跨页规则**：
- **轮次表述统一为前置数字式**（`第 2 轮 · …`），三处（③ 页未达项、⑤ 页页级、⑤ 页上一轮行）**同构**。
- **「上一轮」行仅在轮次 ≥ 2 时显示**；首轮不显示该行（不是显示 `—`）。
- **只读态**：未知字段一律 `.unavailable("—（由更高版本维护）")`，**绝不显示 0**。

## 七、v1.1 变更记录（2026-11-08）

> **裁定人**：颜可读（R3.8 执行人）｜**落地**：程必达｜**依据**：`Residue-DAC-v1.0.md` 的像素级实测
> **裁定原则**：**能靠「改表达方式」解决的，不靠「加新数值」解决。每加一个 token 都是在给下一个人埋一个问号。**

| # | 缺口 | v1.0 的问题 | v1.1 的处置 |
|---|---|---|---|
| **B1** | 表格行高 32 pt 与 ⑤ 页 ③ 列三行文字**数学冲突**（实测 57 pt） | 基线自相矛盾 → DAC-21/22/48 永久不可能通过 | **减内容**：两个冻结时点从每个数据单元格**上移到 ③ 列表头内**分行标注。**数据行统一 32 pt（②⑤⑦ 一致）**，表头块高 60 pt（不计入数据行高）。理由：那两行是**列级元数据**（每行完全相同），逐行重复是噪音；**抬行高只是把信息设计问题变成尺寸问题** |
| **B2** | 信号色「每屏 ≤1」缺逐行标记的处置 | ② 页 3 次 / ④ 页 2 次 / ⑦ 页 2 次，**任何有主行动的页面必然违规** | **改优先级**（主行动 > 焦点环 > 选中态，每屏只兑现最高一个）+ **逐行标记永久不进入信号色**（不是开例外，是明确它不属于合法用途）→ 靠**图标形状**区分，不靠颜色稀缺 |
| **A1** | 「并发冲突」「超时」两态无页面落点 | 只在 ① 页写了并发冲突，超时态无落点 | **并发冲突 = 全局页级状态条**（页头下、内容区顶、通栏、跨页共用）；**超时 = ① 页内容区**（扫描是唯一长任务） |
| **A3** | ⑤ 页「③ 列两个冻结时点」可两解 | 「分行标注」未说明是「同列两行」还是「两列各一」 | **同一列内两行**，且按 B1 已**上移到表头**。不拆列：`样本/总量` 是成对值，拆列破坏配对语义；7 列已占 700 pt，可用宽约 775 pt，再拆必溢出 |
| **A2** | ⑥「抽屉态」算独立页还是某页的抽屉 | 影响信号色计数口径与「7 页 × 1 形态 = 7 ≤ 8」 | ⚠️ **需产品确认，本版不定**。设计师建议 ⑥ **不是第 7 页**，是 ② 页主行动触发的确认抽屉，PRD 口径应改为「6 页 × 1 形态 + 1 抽屉」。**若产品坚持独立页，接受条件是必须同时给「未选中任何条目」的空态**，否则第 7 页是永久空白页 |
